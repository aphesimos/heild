# Planos do produto (cópia de trabalho)

Cópia dos planos do repositório de trabalho `DGM-RAG-Contabil` (14/11/2026), trazida para cá para que as sessões do wireframe interativo trabalhem sem depender de outro repositório. **A fonte da verdade dos planos continua lá**; aqui é leitura. Mudança de plano descoberta durante o wireframe vai para `docs/wireframe/DECISOES.md`, e o coordenador leva de volta.

- `subplanos/01` a `11`: fundações, time de agentes, Painel, CRM, Timesheet, App do cliente, motores e Consultor, conectores, Financeiro, BPO, comunicação interna; `subplanos/juridico/`: pacote Jurídico (JU-01 a JU-12).
- `Desenho_do_Sistema.md`, `Plano_Plataforma_do_Escritorio.md`: visão geral e decisões de arquitetura (DA-01, DA-02, DA-02.1).
- `Cruzamento_Painel_do_Leandro.md`, `Lista_de_Decisao_Painel_do_Leandro.md`, `Cruzamento_Levantamento_Segundo_Escritorio.md`: o que os dois escritórios fazem e o que foi aprovado (regra: tudo agentificado).
- `pesquisa/atividades.json` (590 atividades do Contábil) e `pesquisa/atividades-juridico.json` (234 do Jurídico).
